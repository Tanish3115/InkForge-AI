# InkForge AI

**Typed digital text → handwritten documents.** The app starts in Default Handwriting, with no upload, account, training, API key, or paid service required.

## Start the application

Use Node 22.13+ (tested on 22.14), then run from this folder:

```sh
npm ci
npm run dev
```

Open the printed local URL, choose a style, enter your text, and click **Generate handwriting**. Paper, ink, spacing, seed, and writing controls take effect when you generate. An explicit notice marks an outdated preview; exports use the generated preview. Save drafts locally, and export backups for safekeeping.

## Interface

The studio uses a dark glass interface with animated light, an orbital empty-canvas graphic, smooth transitions, and system reduced-motion support. Handwriting reviews stay inside a bounded scroll area, including large 160-word samples, so the editor and export controls remain reachable. Upload progress is indeterminate while local recognition runs; no artificial completion percentage is shown. Dialogs, long filenames, and recognition labels adapt to desktop and mobile layouts.

## What each engine actually does

| Engine             | Input                                                  | Behavior                                                                                      |
| ------------------ | ------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Browser presets    | Typed text only                                        | Licensed Caveat, Patrick Hand, Kalam, or Marck Script; labeled browser rendering              |
| Uploaded word reuse | Typed text + recognized uploaded word library | Copies matching original word images; only unseen words require neural synthesis |
| Personal glyphs    | Typed text + a saved worksheet/manual-crop profile     | Renders actual extracted transparent ink masks, with multiple variants and baseline alignment |
| Local DiffusionPen | Typed text + five built-in or personal reference crops | Genuine pretrained, style-conditioned diffusion inference in the optional Python service      |

The browser engines work without the neural service. The default web experience uses browser rendering. Connecting a verified local neural service explicitly selects neural mode. No engine silently substitutes another engine after an error.

Default neural conditions use **five synthetic word images derived from licensed handwriting fonts**. They are not IAM writer examples or unconditional generation. Two conditions were verified: Caveat-conditioned and Patrick Hand-conditioned. Neural style cards use actual generated proof images. Personal neural profiles contain five actual word crops; their text does not have to match the requested output. A personal glyph profile is not a neural model.

Neural synthesis has significant text-fidelity limitations on some tested words. Review capitalization, names, spelling, and punctuation. The four browser presets preserve supported text deterministically and remain the dependable default. Extracted glyphs preserve sampled letter shapes; they do not guarantee naturally connected cursive or exact writer replication. Missing glyphs are listed, and export is blocked until corrected or an explicitly labeled preset fallback is chosen.

## Personal handwriting: original word reuse

Upload a clear JPEG/PNG/WebP image in **My handwriting**. The free local service reads its lines using cached TrOCR and saves labeled images of the original words. Type your content, then generate. A matching word now uses its actual uploaded ink rather than being regenerated by DiffusionPen. No dataset-word substitution or handwriting-font approximation is used for these matches.

The original word image keeps its aspect ratio, stroke shapes, shared page scale, and line baseline. Copied words receive no decorative rotation, size jitter, or ink-opacity jitter. Your selected global size, ink color, paper and layout still apply. If an input contains only indexed words, the saved library can render and export without contacting the synthesis service, including after a reload. This does not claim that the whole website is available offline.

Default and personal selections are independent. Returning to **Default handwriting** deselects the active sample, restores the last chosen browser preset, and shows Classic, Neat, Casual, and Flowing. Clicking a preset always uses that browser font. **Deselect sample** or the empty **Choose a profile** dropdown option clears the selection while keeping its saved library. An explicitly selected default neural engine uses a separate reference-condition control and never receives uploaded samples.

The library displays how many typed words have matches. Matching preserves spelling, capitalization and punctuation. Under **Review the text read from your sample**, check the transcript against its image crops. Correct the whole transcript with **Apply corrected labels** when the word count matches, or edit individual word labels. These corrections save locally and immediately update matching. **Use recognized text in editor** copies the reviewed sample text into the digital editor. OCR can make mistakes; copying mislabeled ink cannot certify that the image spells the label.

Only unmatched words go to the existing reference-conditioned DiffusionPen model. The output status reports copied versus synthesized words. New words can still differ in style or spelling and must be reviewed. Older style-only profiles cannot recover the full original document from their five reference crops; upload the original note again once to create its word library. A new upload creates a separate profile.

Upload reading supports clear English handwriting and mild tilt/shadows. Very faint, overlapping, tightly spaced or complex page layouts may be read incorrectly. The service rejects blank/unreadable pages instead of saving an empty word library. Limit each upload to 40 lines and 160 word crops; neural requests permit 80 distinct unmatched words of at most 38 characters. The maximum image size is 25 MiB / 40 megapixels before browser downscaling.

The local service must run for new upload recognition. It loads `microsoft/trocr-small-handwritten` with `local_files_only=True` from `.cache/huggingface/hub`, and exposes `/recognize-sample`. The checkpoint is already cached on the verified machine. To install it on another machine once (free model download; network required):

```sh
python -c "from transformers import TrOCRProcessor, VisionEncoderDecoderModel; n='microsoft/trocr-small-handwritten'; c='.cache/huggingface/hub'; TrOCRProcessor.from_pretrained(n,cache_dir=c,use_fast=False); VisionEncoderDecoderModel.from_pretrained(n,cache_dir=c)"
```

Text and images stay in the browser and the loopback service at `127.0.0.1:8000`; no paid inference hosting is used. Profiles and word labels are stored in IndexedDB and included in profile JSON backups. Export backups before clearing browser data.

## Advanced personalization and documents

Neural generation reuses one seeded diffusion latent and the same reference conditioning across all words in a document, instead of reseeding every word. Reordering words therefore does not change their generated images at the same seed. Personal mode also limits decorative size, rotation, baseline, and opacity jitter to subtle amounts. Changing the document seed changes the shared realization. This reduces avoidable variation; the pretrained word model can still vary letterforms and does not guarantee a perfectly uniform writer style or correct spelling.

- Download the two-page **A4 worksheet**. Fill it with a dark pen, keeping all four black markers visible.
- Upload each page, select its page number, review automatic alignment or manually select the four marker centers, then extract.
- Review real character masks, warnings, labels, and baselines. Delete poor samples or add replacements using **Manual glyph crop**. Labels can include short ligatures.
- Save, rename through profile editing, import/export, delete, and reuse profiles in IndexedDB.
- Optionally, for manual neural references, crop five readable words from uploaded natural handwriting and save a reference profile. Choose the local neural engine.
- Saved documents contain text, style/profile references, settings, seed, and engine selection. Export/import editable JSON document backups; export a personal profile separately if the document uses it.

Page sizes: A4 and US Letter. Paper: plain, ivory, ruled, grid, dotted. Controls: writing size, word/line/letter spacing, margins, ink color/opacity, slant, and seeded variation. Neural word images do not support independent letter spacing, so that control is disabled in neural mode. Font shaping is retained within browser words; personal ligatures use greedy character mapping.

Exports are generated from the rendering engine, not website screenshots: multipage PDF, selected-page PNG, or all PNG pages in a ZIP. PNGs use 300 DPI (A4: 2480 × 3508). PDF page dimensions match the selected paper size. Raster glyph sharpness depends on sample quality. Text is limited to 30,000 characters and 60 pages to bound memory; large exports may still need substantial device memory. Neural requests support up to 80 distinct words with at most 38 characters per word.

Browser rendering and profile extraction stay on this device. Neural text and reference crops go only to the optional service at `127.0.0.1:8000` when selected. No tracking or paid inference endpoint is included. Browser storage can be cleared and is not permanent backup. The first visit needs website/font assets; fully offline operation is not claimed.

## Optional genuine neural service

The service uses the MIT-licensed [official DiffusionPen architecture](https://github.com/koninik/DiffusionPen) and [pretrained EMA/style weights](https://huggingface.co/konnik/DiffusionPen), with the SD1.5 VAE and DDIM scheduler. The upstream UNet is retained under `server/vendor` with its license; a small forward-path change permits caching Canine hidden states between diffusion steps. Nested DataParallel checkpoint prefixes are normalized and weights load strictly. No IAM data is downloaded by setup or used as public default references.

```sh
python -m venv research/.venv
# Activate the environment, then:
python -m pip install -r research/requirements.txt
python server/setup.py
python research/verify_model.py --steps 50
```

Setup downloads roughly 1 GB of actual model assets into ignored `.cache/diffusionpen-model`. Inspect the generated `proof/*-hello.png` and `proof/*-future.png` images. Only after reviewing the actual output:

```sh
python research/verify_model.py --steps 50 --record-reviewed-styles classic neat
python -m uvicorn server.app:app --host 127.0.0.1 --port 8000
```

The upload flow checks the service automatically; **Check local neural service** is also available in the Studio. Readiness is unavailable until model assets and a reviewed verification record exist. `/health`, `/styles`, and `/generate` are real endpoints. Inference loads one reusable model and serializes requests. CORS defaults to the local Vite/preview origins; set `INKFORGE_ORIGINS` explicitly if using another trusted frontend. Bind the service to loopback. Public browser private-network rules may prevent a hosted website from reaching a local service; local Vite usage is the verified integration.

This machine executed genuine 50-step CPU inference. CUDA is selected if available, but GPU execution was not tested here. CPU requests may take seconds per word and initialization adds time; no guaranteed latency is promised. Hardware/model failures return a clear error, and browser generation remains available. Production still uses the pretrained weights; the tiny fine-tuned checkpoint is a separately evaluated research artifact.

## Real IAM synthesis research

The existing `../lines`, `../ascii`, and `../xml` directories are used locally. `research/unpack.py` safely handles the original archives if needed. No dataset images, archives, checkpoints, or experiment outputs belong in a public Git repository or the static website.

```sh
python research/dataset.py --root .. --output research/data/synthesis
python research/train.py --train research/data/synthesis/train.jsonl --validation research/data/synthesis/validation.jsonl --epochs 2 --batch-size 1 --accumulation 4 --output research/runs/synthesis
python research/evaluate.py --manifest research/data/synthesis/validation.jsonl --fine-tuned research/runs/synthesis/best.pt --max-samples 16 --steps 50 --output research/runs/evaluation
python -m unittest discover -s research -p test_synthesis.py
```

Preparation validates line images, XML/ASCII writer identities, and word boxes. It excludes IAM lines flagged with word-segmentation errors and records damaged-record exclusions. From the supplied data it prepared **96,422 word examples / 657 writers**, with **78,564 training**, **9,730 validation**, and **8,128 test** words. Writer sets are disjoint within this experiment. Word images are cropped from line images using XML coordinates. Five same-writer reference crops come from different lines and exclude the target text.

Training adapts the actual DiffusionPen architecture: pretrained VAE latents, text conditioning, pretrained style embeddings, noise timesteps, denoising MSE, backpropagation, AdamW, gradient accumulation/clipping, early stopping, checkpoint saving/loading, and experiment logging. CUDA mixed precision is enabled when available. The VAE/style encoder/Canine backbone remain frozen; diffusion weights are trainable. Resume trusted local optimizer state with `--checkpoint <last-weights.pt> --resume <resume.pt>` and identical data arguments. `--max-train` and `--max-validation` permit bounded smoke runs. A loss graph is generated from completed epochs.

**Actual executed experiment:** CPU, 8 training word targets, 4 validation targets, two epochs, batch size 1, accumulation 4. Real checkpoints are in `research/runs/synthesis-smoke`; losses were **0.07176 / 0.10192** (training/validation, epoch 1) and **0.06694 / 0.10033** (epoch 2). This is a pipeline execution check, not full-dataset training or evidence of improved generalization.

`research/evaluate.py` compares pretrained/fine-tuned and default/personalized synthesis on the same requested words. A separate TrOCR recognizer measures corpus CER/WER. The style encoder's cosine similarity is an uncalibrated style proxy, not a percentage accuracy or human readability score. Human readability is not numerically rated. Generated images, predictions, errors, latency, and plots are saved.

Actual four-word evaluation (23 reference characters), at 50 steps:

| Condition                 |    CER |  WER | Style cosine | Mean seconds / word |
| ------------------------- | -----: | ---: | -----------: | ------------------: |
| Pretrained / default      | 82.61% | 100% |        0.215 |                5.64 |
| Pretrained / personalized | 26.09% |  50% |        0.630 |                4.32 |
| Fine-tuned / default      | 69.57% |  75% |        0.219 |                3.24 |
| Fine-tuned / personalized | 26.09% |  50% |        0.613 |                3.19 |

Results are in `research/runs/synthesis-evaluation/metrics.json`; real loss/comparison PNGs are alongside the runs. The tiny sample is not representative. CER/WER include insertions and may exceed 100%. The independent recognition architecture can itself make transcription errors. Timing excludes initialization and was collected on this machine under varying CPU load, so it is not a controlled speed comparison.

Both pretrained synthesis and recognition models used IAM. These IAM results can overlap pretraining and do **not** establish unseen-writer accuracy. Broader evaluation with consented independent samples, human readability ratings, and full fine-tuning remains research work. The pretrained model is retained; no superior fine-tuned production model is claimed.

For Colab Free, use the same scripts and your authorized IAM files in a private session/Drive, select an available free GPU, and begin with `--epochs 1 --max-train 128 --max-validation 16`. Put `--output` on persistent Drive storage and resume checkpoints after interruption. Free GPU availability/time is not guaranteed; no Colab execution was performed in this session.

## Testing and deployment

```sh
npm run test
npm run build
npm run preview
# With a local frontend running:
npm run test:e2e
# PowerShell opt-in genuine neural test:
$env:INKFORGE_NEURAL_TEST='1'; npm run test:e2e
```

Tests cover deterministic layout, wrapping, paragraph gaps, dimensions, registration transforms, profile validation, actual no-upload rendering, distinct styles, actual glyph extraction/persistence, high-resolution exports, missing characters, backend failure, mobile layouts, and real optional local neural generation. Browser tests use installed Edge on Windows; otherwise install Chromium using `npx playwright install chromium`. Set `INKFORGE_URL` to test a static preview or deployment. Private IAM references are used only for local research tests and never bundled.

Executed verification: 13 unit tests, 3 Python research tests, and 6 Edge browser workflows passed. The browser suite also passed against the static production build, including real neural default generation and five-reference personalization. TypeScript, unused-symbol checks, and the production build passed.

Cloudflare Pages: project root `inkforge-ai` if deploying the parent repository; build `npm run build`; output `dist`; Node 22.13+. Use a free `pages.dev` domain. The static build contains fonts and application code, and supports presets/personal glyphs without a server. It excludes neural checkpoints, research data, and Python. No public Cloudflare deployment was performed in this session; the production static bundle is tested locally.
